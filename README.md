**React Auth App**

A simple authentication application built with React and React Router.

This project demonstrates a basic login, registration, protected routes, logout functionality, and persistent authentication using browser localStorage.

**Features**

User registration

User login

User logout

Protected dashboard

Authentication state management with React Context

Persistent login after page refresh

Form validation

Password confirmation

Error handling

Responsive and simple UI

**Tech Stack**

React

React Router DOM

JavaScript

CSS

Vite

Browser LocalStorage



**Installation**

**Clone the repository:**

git clone https://github.com/Kishor6203/react-auth-app.git


**Go into the project directory:**

cd react-auth-app


**Install dependencies:**

npm install


**Start the development server:**

npm run dev


**Open the application in your browser:**

http://localhost:5173
